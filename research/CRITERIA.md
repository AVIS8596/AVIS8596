# 唐奇安策略真实数据检验: 事先确定的及格线

本文件在查看任何真实数据回测结果**之前**写定并提交, 之后不修改标准。

## 被检验的对象

`integrations/quantdinger/donchian_breakout_v2.py` (QuantDinger 版唐奇安突破 + ATR 风控),
用与 QuantDinger 引擎逐笔一致的 `mock_runtime.py` 运行 (加入手续费与滑点)。

## 数据

Binance 现货日线 (公开行情 `data-api.binance.vision`), 从各交易对上市到最近一根已收盘 K 线。

- 调参用: BTCUSDT、ETHUSDT
- 只用于检验、不参与调参: BNBUSDT、SOLUSDT、XRPUSDT、ADAUSDT

## 成本

手续费 0.1% / 边 + 滑点 0.05% / 边 (压力测试: 两者翻倍)。

## 方法

1. 参数网格: entry_period ∈ {10, 20, 30, 40, 55}, exit_period ∈ {5, 10, 20},
   stop_atr ∈ {0 (关闭), 2, 3}; 其余参数保持默认 (trailing=true, risk_per_trade=0.02,
   max_position_pct=0.95)。回撤熔断在检验中关闭, 单独报告它会在何时触发。
2. 滚动窗口 (walk-forward): 用过去 2 年选夏普最高的参数, 在随后 1 年检验, 每年滚动一次;
   把各年的检验段拼接成一条完全样本外的收益曲线。
3. 基准: 同一时间段买入持有。

## 及格线 (全部满足才算通过)

| # | 标准 |
| --- | --- |
| C1 | BTC 与 ETH 的样本外拼接结果: 扣除成本后总收益 > 0, 且夏普 ≥ 买入持有夏普的 0.8 倍 |
| C2 | BTC 与 ETH 的样本外最大回撤 ≤ 买入持有最大回撤的一半 |
| C3 | 默认参数 (20/10/2) 在 BTC、ETH 全期扣成本后夏普 > 0, 且整个网格中 ≥ 70% 的参数组合夏普 > 0 (参数不敏感) |
| C4 | 成本翻倍后, BTC 与 ETH 样本外夏普仍 > 0 |
| C5 | 默认参数在 4 个未参与调参的币种中至少 3 个扣成本后夏普 > 0 |

任一条不满足即判定"不建议投入真实资金", 不再为了过线修改策略或标准。
