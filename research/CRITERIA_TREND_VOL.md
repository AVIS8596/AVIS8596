# 多周期趋势 + 波动率目标策略: 事先确定的及格线

本文件与策略代码 `integrations/quantdinger/trend_vol_target_v2.py` 一起, 在用该策略跑任何真实数据**之前**提交, 之后不修改。

## 被检验的对象

`trend_vol_target_v2.py` 的默认参数, **不做任何参数优化**:
回看 20/60/120 天, 波动率窗口 30 天, 目标年化波动 50%, 最大仓位 95%, 调仓阈值 10%, 回撤熔断关闭。
用与 QuantDinger 引擎逐笔一致的 `mock_runtime.py` 运行。

## 数据与成本

Binance 现货日线 (公开行情 `data-api.binance.vision`), 从各交易对上市到最近一根已收盘 K 线。
每个币种的评估区间从第 150 根 K 线开始 (指标预热之后), 买入持有基准使用同一区间。
手续费 0.1% / 边 + 滑点 0.05% / 边。

- **未看过的币种 (主要检验)**: LTCUSDT、TRXUSDT、ETCUSDT、XLMUSDT、LINKUSDT、DOGEUSDT、BCHUSDT、ATOMUSDT
- **上次已看过的币种 (要求更严)**: BTCUSDT、ETHUSDT、BNBUSDT、SOLUSDT、XRPUSDT、ADAUSDT

已知局限: 只能取到今天仍在 Binance 交易的币种, 存在幸存者偏差; 策略思路的选择受到上一次检验结果的启发。

## 及格线 (全部满足才算通过)

| # | 标准 |
| --- | --- |
| C1 | 未看过的 8 个币种中, 至少 6 个扣成本后夏普 > 0 |
| C2 | 未看过的 8 个币种中, 至少 6 个策略夏普 > 买入持有夏普 |
| C3 | 未看过的 8 个币种全部: 策略最大回撤 < 买入持有最大回撤; 且策略最大回撤中位数 ≤ 买入持有中位数的 60% |
| C4 | 看过的 6 个币种中至少 5 个策略夏普 ≥ 买入持有夏普; 且 BTC、ETH 的年化收益 ≥ 买入持有年化收益的 40% |
| C5 | 成本翻倍: 未看过的币种中至少 6 个夏普 > 0; BTC、ETH 夏普 ≥ 买入持有夏普的 0.8 倍 |
| C6 | 参数敏感性: 回看周期 ×0.5 / ×1 / ×2、目标波动 30% / 50% / 70%、调仓阈值 5% / 10% / 20% 共 27 组, BTC 与 ETH 上各自至少 80% 的组合夏普 > 0 |
| C7 | 不靠单一年份: 去掉收益最好的自然年后, BTC、ETH 的累计收益仍 > 0, 未看过币种的累计收益中位数仍 > 0 |

另外报告 (不作为判定): 逐年收益、平均仓位、交易次数, 以及 35% 回撤熔断会在何时触发。

任一条不满足即判定"不建议投入真实资金", 不再为了过线修改策略、参数或标准。
