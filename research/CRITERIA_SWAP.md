# 永续合约多空版趋势策略: 事先确定的及格线

本文件与策略代码 `integrations/quantdinger/trend_vol_target_swap_v2.py` 一起, 在用该策略跑任何永续合约真实数据**之前**提交, 之后不修改。

## 要回答的问题

在现货只做多版 (`trend_vol_target_v2.py`) 的基础上**允许做空**, 扣除手续费、滑点和真实资金费之后, 是否更好?
如果不是, 结论就是"不需要用永续合约, 只用现货版"。

## 被检验的对象

`trend_vol_target_swap_v2.py` 的默认参数, **不做任何参数优化**, **不加杠杆** (最大仓位 95%):
三个回看周期 20/60/120 天各投 +1/−1 票, 平均值 × 波动率目标仓位 (目标年化波动 50%), 调仓阈值 10%;
反手时先平仓, 之后的 K 线再开反向仓。用与 QuantDinger 引擎逐笔一致的 `mock_runtime.py` 运行。

对照组: 现货只做多版, 默认参数, 在**相同日期区间**的 Binance 现货日线上运行。

## 数据与成本

- 永续合约: Binance USDT 本位永续日线与历史资金费率 (`data.binance.vision` 月度归档 + 当月日度归档), 从各合约归档最早月份到最近一根已收盘 K 线。
- 币种 (14 个): BTC、ETH、BNB、SOL、XRP、ADA、LTC、TRX、ETC、XLM、LINK、DOGE、BCH、ATOM (均对 USDT)。
- 每个币种的评估区间从合约数据第 150 根 K 线开始; 两个版本使用同一区间, 之前的数据只作预热。
- 手续费 0.1% / 边 + 滑点 0.05% / 边; 资金费按每日实际费率之和 × 收盘持仓名义价值结算 (多头在正费率时支付, 空头收取)。

已知局限: 这 14 个币的价格走势在之前的检验中已经看过 (现货与合约价格几乎相同), 真正新的部分只有做空; 幸存者偏差; 资金费按日汇总近似。

## 及格线 (全部满足才算通过)

| # | 标准 |
| --- | --- |
| C1 | BTC 与 ETH: 合约多空版夏普 ≥ 现货只做多版夏普 |
| C2 | 14 个币种中至少 9 个: 合约多空版夏普 > 现货只做多版夏普 |
| C3 | 14 个币种中至少 11 个: 合约多空版扣除全部成本后夏普 > 0 |
| C4 | 空头部分本身赚钱: 只统计持空仓日子的收益 (含手续费与资金费), BTC、ETH 各自累计 > 0, 且 14 个币种的中位数 > 0 |
| C5 | 风险: BTC、ETH 合约多空版最大回撤 ≤ 60%; 14 个币种最大回撤中位数 ≤ 现货只做多版中位数 + 10 个百分点 |
| C6 | 压力测试 (手续费与滑点翻倍、资金费 × 1.5): BTC、ETH 夏普仍 > 0, 且至少 9/14 个币种夏普 > 0 |

另外报告 (不作为判定): 累计资金费、逐年收益、多空持仓天数占比。

任一条不满足即判定"不建议使用永续合约版", 不再为了过线修改策略、参数或标准。杠杆不在本次检验范围内。
